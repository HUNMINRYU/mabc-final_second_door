01 · 문제 정의

문제

메시지 하나로 "진짜일까?"를 판단하려다
이체·자격증명 입력·링크 방문·설치·원격접속을 바로 해버린다.

이 서비스가 하지 않는 것 / 하는 것

  • 사용자는 "안전하다/사기다" 같은 진위 판정을 기대하지만, 이 서비스는 판정하지 않는다.
  • 메시지에 포함된 번호·계좌·URL을 그대로 믿고 반복하게 된다.
  • 급한 압박을 받으면 이미 알고 있던 경로(저장된 번호 등)로 확인할 생각을 못 한다.
  • 특히 부모·가족 관계에서 "자녀/지인이 급하다"며 계좌·링크·번호 변경을 요구하는 메시지일 때, 중장년층·디지털 문해력이 높지 않은 사람이 위험에 노출된다.

언제 쓰는가 (트리거)

1의심스러운 문자·카톡·이메일·메시지를 받았다.
2"이거 어떻게 해야 하지?" 하는 순간, URL로 접속해 메시지를 붙여넣는다.
3분석 버튼을 누르면, 판단 대신 멈추고 확인하는 절차가 정리되어 나온다.

= 불러 쓰는(on-demand) 서비스. 알림·공유 링크은 P1. 별도 로그인·키 입력 없음.

02 · 해결 방식

핵심 기능

메시지를 붙여넣으면 7개 필드가 순서대로 나온다.
분기와 금지 패턴, 예시까지 한 화면에서 보여준다.

① 메시지 입력 → 7개 필드 출력

#필드
1상태
2중단조치
3확인할주장
4독립확인
5답장예시
6판단이유
7하지말것

입력은 텍스트 영역 하나. 출력 결과는 받은 사람이 바로 이해할 수 있게 카드 형태로 표시.

② 분기 표시 + 판단이유

내부 분기 즉시중지 > 먼저확인 > 일반 > 입력필요를 상단 뱃지로 보여주고, 판단 근거로 판단이유를 표시한다.

⚠ 즉시중지 🔍 먼저확인 📄 일반 ✏️ 입력필요

③ 금지 패턴 검사 결과

출력에 아래 내용이 포함되지 않도록 검사하고, 걸렀음을 보여준다.

  • 사기·진짜·가짜·안전 판정, 점수/확률/%, 긴급번호 숫자
  • 제공된 식별자(번호·계좌·링크) 반복
  • 복구·환불·배상·보장 약속
  • 자격증명 입력·링크 열기·이체·설치·원격접속 등

④ 예시 프리셋 데모

버튼 하나로 예시 메시지를 넣고 바로 분석 결과를 시연할 수 있다.

아들 급전(계좌) → 즉시중지 새 연락처 변경 → 먼저확인 이미 보냄 압박 → 즉시중지 일반 의심 → 일반 빈 메시지 → 입력필요

03 · 스킬 매핑 · 기술

예선 스킬을 서비스 로직으로

예선 당선 스킬 second-door (두번째문)을 서비스 핵심 로직으로 그대로 이식했다.
Solar Pro 4 API 키 없이 동작한다.

예선 스킬 → 서비스 로직 매핑

기능사용 스킬비고
7개 필드 생성 + 분기 선택 + 금지 패턴 검사 second-door 예선 스킬을 서비스 핵심 로직으로 이식. /api/analyze 서버리스 함수가 스킬의 데이터 경로(분기 규칙·출력 계약·금지 패턴)를 그대로 구현
판단이유 문장 보강(선택·P1) Solar Pro 4 (Upstage) 키를 쓰면 더 자연스러운 문장 생성. 키 없으면 규칙 기반 문장으로만 동작

핵심 원칙: 예선 당선 스킬이 서비스 핵심 로직에 필수 포함. 서비스화를 위한 수정·확장은 허용.

기술 스택

  • Next.js 16 (App Router) + React 19 + TypeScript
  • Vercel 배포 (서버리스 API Route /api/analyze)
  • 규칙 기반 로직 — 키 없이 동작

API

GET /api/analyze — 서비스 정보 (건강 체크)
POST /api/analyze — {"message":"..."} → 7개 필드 응답

예:
curl -X POST https://mabc-second-door.vercel.app/api/analyze
-H "Content-Type: application/json"
-d '{"message":"..."}'

규칙/계약 (결선 규정 반영)

  • LLM: Solar Pro 4 전용. 타 LLM(Claude, GPT 등) 사용하지 않음.
  • 키 정책: 기본 동작은 키 없이 동작. Solar 호출 보강(P1)은 선택 사항이며, 키는 Vercel 환경변수에만 — 화면 코드·응답 JSON·클라이언트 소스에 절대 노출되지 않음.
  • 출력 계약: 진위 판정, 점수/확률/%, 식별자 반복, 긴급·기관 번호 숫자 제시, 복구·환불·배상 보장 하지 않음.
  • MCP/데이터: MCP 허용, 저작권 범위 내 데이터는 활용 가능.

데모 시연 흐름 (3분)

1아들 사칭 급전 메시지 → 즉시중지 + 7개 필드 + 계좌 식별자가 "메시지 속 계좌"로만 표시
2새 연락처로 바꾸라는 메시지 → 먼저확인
3빈 메시지 → "메시지가 필요합니다" 안내 + 입력필요
4시크릿 창 재방문 → 별도 로그인 없이 안내 → 분석
5검증 포인트: 식별자 미유출, up_ 키 0건, 금지 패턴 없음
