# 두번째문 서비스 MVP — 미니 PRD

> 출처 태그: [문서추론] = second-door SKILL.md(추출본) + skill-to-service 가이드 + MABC 2026 결선 가이드에서 읽은 내용을 근거로 작성. [실행] = 2026-09-13 Vercel 배포본에서 실제 curl/ego-browser로 확인한 결과.

## 1) 한 줄 정의
의심스러운 메시지를 받은 사람이, 진위 판정 없이 **멈추고 독립 확인할 절차를 7개 필드로 정리**해 보여주는 웹 서비스.

## 2) 타깃 사용자 (WHO — 구체적 한 사람)
부모·가족 관계에서 "자녀/지인이 급하다"며 계좌·링크·번호 변경을 요구하는 메시지를 받는 사람. 예: 중장년층, 디지털 문해력이 높지 않고 급한 마음에 바로 이체/응대할 위험이 있는 사람. [문서추론 — second-door 예시(입력: "아들 급합니다. 병원비 입금…Toss 3333-12-345678") + 타겟 narrowing 질문 응답]

## 3) 문제
- 메시지 하나만으로 "진짜일까?"를 판단하려다 **송금·자격증명 입력·링크 방문·설치·원격접속** 같은 행동을 바로 하게 됨
- 진위 판정은 이 서비스가 하지 않는데, 사용자는 "안전하다/사기다" 같은 답을 기대함
- 메시지에 포함된 전화번호·계좌·URL을 그대로 믿거나 반복하게 됨
- 긴급한 압박을 받으면 이미 알고 있던 독립 경로(저장된 번호로 전화 등)로 확인할 생각을 못 함

## 4) 트리거 (WHEN — 언제 쓰는가)
- 의심스러운 문자/메시지를 받아서 "이거 어떻게 해야 하지?" 하는 순간
- 언제든 URL로 접속해 메시지를 붙여넣음 (웹 서비스 기본 = 언제든 옴)
- = **불러 쓰는(on-demand)** 서비스. 알림·공유 링크는 P1.

## 5) 핵심 기능

### P0 (결선 데모 필수 — 최대 4개)
1. **메시지 입력 → 7개 필드 출력** — 텍스트 영역에 메시지를 붙여넣고 분석 버튼을 누르면 `상태 / 중단조치 / 확인할주장 / 독립확인 / 답장예시 / 판단이유 / 하지말것` 7개 필드를 순서대로 보여줌. [문서추론 — second-door 출력 계약 7필드 순서]
2. **분기 표시 + 판단이유** — 내부 분기(`즉시중지 > 먼저확인 > 일반 > 입력필요`)를 사용자가 볼 수 있게 표시하고, 왜 그 분기로 봤는지 근거를 `판단이유`로 보임. [문서추론 — 분기 선택 규칙 + 출력 계약]
3. **금지 패턴 검사 결과** — 출력에 사기·진짜·가짜·안전 판정, 점수/확률/%, 제공된 식별자 반복, 긴급번호 숫자, 복구·환불 보장, 적극적 금지행동(자격증명입력·링크열기·이체·설치·원격접속) 등이 포함되지 않도록 검사하고, 걸렀음을 표시. [문서추론 — 금지_출력범주 + 개인정보 가리기 규칙]
4. **예시 프리셋 4종 데모** — 분기 4종(긴급 이체형 → 즉시중지, 번호 변경형 → 먼저확인, 압박 메시지 → 즉시중지, 일반 안내형 → 일반)을 버튼 하나로 넣어 바로 시연 가능. [문서추론 — QA 8개 fixture 방향 + second-door 예시 1·2·3]

### P1 (하면 좋은 것)
- **결과 공유 UX**: 분석 결과를 URL로 공유할 수 있게 "링크 복사" 제공. 시크릿 창에서도 동작해야 함. [문서추론 — skill-to-service 성공 기준 "시크릿 창 테스트 포함" + UX "가족 공유"]
- 메시지 전처리 안내(최소 입력 안내, 개인정보 가리기 안내)
- 다크 모드 / 글자 크기 조절 (CSS dark mode + 상대 단위)
- "저장된 독립 확인 경로"를 브라우저에 기억(localStorage) — 재방문 시 다시 묻지 않음, 초기화 버튼 제공 [문서추론 — skill-to-service SETUP ④ 설명]
- Solar Pro 4 호출로 판단이유 문장 보강(선택) — 키 없으면 규칙 기반으로만 동작 [문서추론 — Hermes 크레딧 $50, Solar 호출 옵션]

## 6) 스킬 매핑
| 기능 | 사용할 예선 스킬 | 비고 |
|------|----------------|------|
| 7개 필드 생성 + 분기 선택 + 금지 패턴 검사 | **second-door (두번째문)** | 예선 스킬을 서비스 핵심 로직으로 이식. `/api/analyze` 서버리스 함수가 스킬의 데이터 경로(분기 규칙·출력 계약·금지 패턴)를 그대로 구현 [문서추론 — skill-to-service PRD 항목6] |
| 판단이유 문장 보강(선택·P1) | Solar Pro 4 (Upstage) | 키를 쓰면 더 자연스러운 문장 생성. 키 없으면 규칙 기반 문장으로만 동작 |

**핵심 원칙**: 예선 당선 스킬(second-door)이 서비스 핵심 로직에 필수 포함. 서비스화를 위한 수정·확장은 허용. [문서추론 — 결선 제출 가이드 "예선 당선 스킬을 서비스 핵심 로직에 필수 포함"]

## 7) 입력·출력 (INPUT/OUTPUT)
**입력:**
- 텍스트 영역: 분석할 메시지 원문 (한 줄 이상, 길게도 가능)
- 선택: "이미 알고 있던 확인 경로" 메모 (예: "아들 저장 번호", "은행 공식 콜센터") — 있으면 독립확인 필드가 더 구체화됨. 없어도 서비스 동작에는 지장 없음.

**출력 (화면):**
- 7개 필드를 **순서대로 한 섹션씩** 카드/목록 형태로 표시
- 상단에 현재 분기(`즉시중지`/`먼저확인`/`일반`/`입력필요`) 배지
- P3에서 금지 패턴 검사 결과(걸러진 항목) 표시
- 하단: "이 결과는 진위 판정이 아닙니다" 안내 + 시크릿 창/공유 주의 안내

**입력은 설명 없이도 넣을 수 있을 만큼 단순하게**, 출력은 받은 사람이 바로 이해할 수 있게 카드 형태로. [문서추론 — INPUT/OUTPUT 걸음 + 출력 계약 형태]

## 8) 필요 설정 (SETUP)

### 8-1. 배포 연결

- Vercel 커넥터/CLI로 배포. 값은 Vercel 환경변수에만. [문서추론 — skill-to-service SETUP + Vercel 배포 레시피]

### 8-2. 서비스 키 (Vercel 환경변수) — 값 금지, 이름·용도·발급처만
| 이름 | 용도 | 발급처 | 값 |
|------|------|--------|-----|
| (없음) | **기본 모드(규칙 기반)는 키가 필요 없음** | — | — |
| `UPSTAGE_API_KEY` | (P1) Solar Pro 4 호출로 판단이유 보강 시 사용 | Upstage Console → API keys | **절대 코드/출력에 적지 않음** |

### 8-3. 사용자 프로필 (웹 화면 입력 → localStorage)
- "이미 알고 있던 확인 경로" 메모 (선택): 재방문 시 다시 묻지 않음
- 초기화 버튼 제공
- 서버에는 보내지 않음 (브라우저에만) [문서추론 — SETUP ④]

## 9) 데이터 규칙
- 출처·기준 시각 표기: 이 서비스는 실시간 사실이 아니라 **스킬 계약 기반 정리**이므로, 출력 하단에 "이 결과는 메시지 진위를 판정하지 않으며, 독립 확인 절차를 정리한 것입니다" 문구를 고정 표시 [문서추론 — second-door "진위 판정 안 함"]
- 없는 값은 '확인 불가'로 표시
- 추정 금지: 메시지 내용에 없는 사실(보낸 사람 실제 신원 등)을 만들어 쓰지 않음
- 키·프록시 주소는 서버(/api)에만, 클라이언트 소스·응답 JSON·화면 코드에는 0 [문서추론 — skill-to-service 데이터 규칙]
- 최소 권한: Solar 호출을 쓰는 P1에서도 프롬프트에 메시지 원문만 보내고, 출력 결과의 금지 패턴 검사에는 식별자 범주만 사용

## 11) 제외 범위
- 메시지 진위 판정(사기/진짜/안전 등)을 하지 않음 — 이 서비스는 "확인 절차 정리"만 제공
- 실제 이체·링크 방문·설치·원격접속·자격증명 입력을 대행하지 않음
- 긴급 기관 번호(112/119/1332/1366/1398/1345 등) 숫자를 제시하거나 지어내지 않음
- 복구·환불·배상·결과 보장을 약속하지 않음
- 이미지 첨부 메시지 분석, 실시간 알림 발송, 다국어 번역, 대량 동시 처리 등은 범위 밖 (P1도 아님 — 제외)
- Solar Pro 4 외 다른 LLM(Claude·GPT 등) 사용 안 함 [문서추론 — 결선 그라운드룰 "LLM은 Solar Pro 4 전용"]
